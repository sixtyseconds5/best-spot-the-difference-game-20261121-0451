Twin Lantern Hunt is a spot-the-difference game with three original
canvas-painted scenes (Cozy Library, Seaside Market, Night Observatory),
seven hidden differences per scene, markers on both pictures for every
find, a big remaining counter, score, timer, mistakes, hints with a
pulsing ring, pause, star-rated win screens, and full keyboard play
(arrows move the crosshair, Enter marks, H hint, 1–3 scenes, P pause).
It runs offline from static files with no network request.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
